Help Center

Everything you need to know to get files from a public TeraBox link.

Getting a file
  1. Copy a public TeraBox share link from the TeraBox app or website.
  2. Paste it into the box on the homepage.
  3. Click Get files and wait a few seconds while it's processed.
  4. Once files are found, click Download on any file — or Download all if there's more than one.
Password-protected shares

If the link owner set a password on the share, click This link is password protected under the input box and enter the password before submitting.

Supported links

TeraGrab works with public TeraBox share links (the kind you get from a "Share" button in TeraBox), across TeraBox's supported domains. Private files that haven't been shared, or links that have expired or been deleted, can't be resolved.

Common problems
  • Invalid link — double-check you copied the full share URL.
  • No files found — the share may have expired or been removed by its owner.
  • Download unavailable — the file's direct link isn't accessible right now; try again shortly.
Is my data safe?

TeraGrab doesn't require an account, doesn't ask for your TeraBox login, and doesn't store the files you download. It only relays the public share information to your browser.

Browser & mobile support

TeraGrab works in any modern browser on desktop, Android, and iOS — no app install needed. If a download doesn't start automatically on mobile, check your browser's downloads folder or notification tray.
